# La Porte Municipal Airport — independent website concept

This is a static, responsive HTML concept site. It is explicitly labeled as independent and is not an official City of La Porte website.

## Publish
The included GitHub Actions workflow deploys this site to GitHub Pages on pushes to the main branch. In GitHub, open Settings → Pages and confirm the deployment source is set to GitHub Actions.

## Important
Before representing this as an official airport website, obtain written authorization from the City of La Porte and have city staff review all content. Airport information, business listings, phone numbers, and links can change; verify them before publication.
